# Возврат с последней страницы

Причина чёрного экрана: общий TopNavBar выполнял Navigator.pop даже при отсутствии предыдущей страницы. После прямого открытия раздела GoRouter сообщал currentConfiguration.isNotEmpty, затем Navigator блокировался (_debugLocked).

Оба варианта кнопки в общем TopNavBar используют проверку Navigator.canPop: обычный возврат сохраняется; при единственной странице открывается HomeRoute. Данные и авторизация не сбрасываются.

Регрессионный тест до исправления воспроизвёл исходную ошибку. После исправления 11 тестов общей шапки и навигации главной прошли; анализ изменённых файлов — один informational lint use_super_parameters, ошибок и warnings нет. В iPhone 16 выполнен прямой вход в совместимость → Назад → главная, проверены дерево интерфейса и скриншот. Главная оставлена открытой.
