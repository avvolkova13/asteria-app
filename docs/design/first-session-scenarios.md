# С чего начнём?

На новом профиле после заставки и регистрации открывается выбор из четырёх сценариев. Сохранённая отметка привязана к аккаунту. Выбор карточки или «На главную» завершает первый вход. Позже экран можно открыть через «Профиль» → «С чего начнём?». На этом пути стрелка назад возвращает в профиль, а «На главную» открывает главную вкладку. Прежние вводные слайды сохранены в коде.

| Ситуация | Действие и результат | Как вернуться |
| --- | --- | --- |
| Подобрать день | Выбрать занятие и одну или две даты. Для сравнения берутся оценки занятия в каждом дне. Можно дать плану своё название и сохранить. | «Выбрать день» в блоке «Фаза луны» и «Мои планы» в календаре. |
| Взять минуту для себя | После вопроса «Как вы сейчас себя чувствуете?» открывается доступная запись для выбранного состояния. Для «Всё время спешу» это «У меня есть время» (1 мин 15 с). Если записи для выбранного состояния ещё нет, человек может сам выбрать предложенную аффирмацию для передышки. При нескольких доступных записях для одного состояния плеер открывает их по очереди в пределах текущего сеанса. | Стрелка в плеере возвращает на предыдущий шаг. Из вопроса о состоянии можно вернуться к четырём сценариям. |
| Хочу лучше понять нас | Для чувств и спора приложение предлагает разбор пары. Сохранённая пара использует готовый разбор, новая запускает действующую форму. Поделиться можно конкретным вопросом. Для исследования собственных чувств предлагается любовный расклад с действующим доступом. | Вернуться к ситуации или повторно открыть её через выбор сценариев в профиле. |
| В чём моя сила? | Два коротких выбора определяют ситуацию. Качество и основание берутся из доступной натальной интерпретации. Уместный актуальный фокус дня уточняет действие. При нехватке оснований доступен редакторский совет и штатный путь к натальному разбору. | «Мои подсказки» в сценарии. Запись хранит дату, текст и использованные пояснения конкретного аккаунта. |

## Дизайн

Ориентиры мобильной Figma — [главная](https://www.figma.com/design/iRwq5h8Hi7qqhuFLJ2iEtg/Asteria?node-id=4379-8517), [кнопки UI kit](https://www.figma.com/design/iRwq5h8Hi7qqhuFLJ2iEtg/Asteria?node-id=15-7223), [аффирмация на главной](https://www.figma.com/design/iRwq5h8Hi7qqhuFLJ2iEtg/Asteria?node-id=4379-8612) и [логотип](https://www.figma.com/design/iRwq5h8Hi7qqhuFLJ2iEtg/Asteria?node-id=4507-57799). Сплеш использует один и тот же знак в нативном и Flutter-кадре. Экран выбора собирается из AuthFlowScaffold, HomeSectionHeading и HomeGlassSurface. Для двух дат расширен существующий MoonCalendarWidget. Практика, выбор пары, расклад и натальный разбор используют штатные экраны и ограничения доступа.

## Идея сонника для дальнейшего развития

Сохранять исходный рассказ о сне, дату, толкование и необязательную метку автора. По метке, например «Опоздание · 2 сна», можно будет найти рассказы, в которых повторялся выбранный образ.
